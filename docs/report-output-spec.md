# 帳票出力仕様

## 基本方針

古物台帳および輸出・免税販売の仕入販売相対表は、提供された既存ファイルを正式な帳票仕様とする。独自帳票は定義せず、列名、列順、シート名、見出し、書式、固定文言、数式、印刷設定、文字コード、改行コードおよびファイル名規則をテンプレート版ごとに維持する。

## テンプレート管理

帳票名、原本の安全な複製、バージョン、適用開始日、出力形式、ファイルハッシュおよび解析済み設定を保存する。過去のテンプレートを削除せず、出力履歴に使用版と出力ハッシュを記録する。

## 取込マッピング

### 古物台帳CSV

`日時 / 名前 / ふりがな / 生年月日 / 住所 / 電話番号 / 商品名 / 個数 / 単価 / 金額 / 備考` を既存順序のまま扱う。

### 仕入販売相対表

1行目の `受入れ` と `払出し`、2行目の2回目の `年月日` を境界として動的に判定する。商品区分や帳票版による列数・計算式の差異はテンプレート側を正とする。

## 正式出力前チェック

古物台帳は必須項目、数量・単価・金額の整合、重複候補を確認する。相対表は販売日、対応仕入数量、販売数量と仕入数量の一致、レイアウトを確認する。エラーが1件でもある場合は正式出力を禁止し、確認用出力のみ許可する。

## 機密情報

実データ、テンプレート複製、DB、出力帳票はGit管理外へ保存する。原本を直接変更しない。リポジトリには実データ由来の氏名、住所、電話番号、生年月日、証憑番号、商品明細、金額を保存しない。
